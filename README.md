GoReSym Rename Patched

A patched and enhanced version of the GoReSym Ghidra Python script.

This repository contains a modified version of the original GoReSym Ghidra integration script, with custom fixes and additional improvements to make Go binary analysis and symbol recovery workflows more convenient in Ghidra.

The script works with JSON output generated by GoReSym, helping restore meaningful function names and labels in Go binaries during reverse engineering.

Overview

GoReSym is a tool developed by Mandiant for recovering Go binary metadata, including function names, types, and other runtime information.

The original project provides a Ghidra Python script that imports GoReSym JSON output and applies recovered names to functions and labels.

This repository focuses specifically on the Ghidra integration script, providing a patched version with custom modifications and additional fixes.

This repository is not a replacement for the GoReSym engine. It is intended to complement GoReSym by improving its integration with Ghidra.

Features
Imports GoReSym JSON output into Ghidra.
Renames recovered Go functions.
Handles user-defined and standard library functions.
Creates missing functions where applicable.
Restores useful runtime labels.
Supports address offset estimation.
Includes custom patches and fixes to the original script.
Designed to simplify Go binary reverse engineering workflows.

GoReSym

Installation
1. Clone this repository
bash
git clone https://github.com/ZwNeoRoot/goresym_rename_patched.git

2. Locate the Python script

Navigate to the cloned repository and locate the Ghidra script.

3. Add the script to Ghidra
Open Ghidra.
Open the Script Manager.
Navigate to the script directory configuration.
Add the directory containing the Python script.
Refresh the Script Manager.
Usage
1. Analyze your Go binary

Open the target Go executable in Ghidra and allow the initial analysis to complete.

2. Generate GoReSym JSON output

Run GoReSym against your target binary.

Example:

bash
goresym -t -d -p target_binary.exe > goresym.json


Refer to the original GoReSym documentation for additional command-line options.

3. Execute the Ghidra script
Open the Script Manager.
Locate the GoReSym rename script.
Execute it.
Select the JSON output generated by GoReSym.
Follow the script's prompts.

The script will process the recovered metadata and apply the available function names and labels to the Ghidra program.
